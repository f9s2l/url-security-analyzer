\# 🛡️ URL \& File Security Analyzer



A fast and lightweight security tool built with \*\*Python\*\* and \*\*Streamlit\*\* to scan URLs and document files for malware, phishing threats, and vulnerabilities using the \*\*VirusTotal API v3\*\*.



\## ✨ Features

\- 🔍 \*\*URL Scanning\*\*: Real-time analysis of web links against 70+ antivirus engines.

\- 📁 \*\*File Analysis\*\*: Upload and scan files (PDF, EXE, DOCX, ZIP, etc.) for malware.

\- 📊 \*\*Visual Metrics\*\*: Clear display of malicious, suspicious, and harmless detections.

\- 🔐 \*\*Privacy First\*\*: Secure API key management directly from the user interface.
